### 为什么要单线程
  '同步问题'：由于javascript运行在浏览器中，需要对DOM元素进行操作。如果多线程同时进行DOM操作，则会出现很复杂的*同步问题*。单线程更简单安全。
  
### 那如何处理异步任务
  与“事件循环”机制联系。
  - 由事件循环**处理不能立即执行的任务**（异步任务）。

### 宏任务和微任务的局限
 - 单线程执行：无论是宏任务还是微任务，仍然是在同一个主线程上执行。因此，如果一个任务运行时间过长，还是会阻塞主线程，造成页面卡顿，无法响应用户交互。
 - 无法真正并行：宏任务和微任务可以异步调度，但并非并行执行。如果出现大量或复杂的计算任务，例如*数据处理、图像处理或加密解密，事件循环需要花费大量时间来执行这些任务*，导致 UI 卡顿和不流畅。

### web worker
  是一个独立的线程，但是不能直接访问DOM。
